# BPADASH - Admin Dashboard

Administrative frontend for the BPADASH business management platform.

This project provides the administrative interface used to manage business data and platform operations through a web-based dashboard integrated with backend APIs.

## Features

- Administrative dashboard
- REST API integration
- Data management interfaces
- Tables with filtering, pagination and editing
- Forms and data validation
- Charts and data visualization
- Calendar and date-based features
- Authentication and user access
- Responsive interface
- Internationalization support
- Reusable UI components

## Technologies

- React
- JavaScript
- Vite
- Redux
- Redux Saga
- Axios
- Material UI
- Bootstrap
- Tailwind CSS
- React Router
- Formik
- React Hook Form
- Yup
- ApexCharts
- Recharts
- Chart.js
- Firebase
- i18next

## Architecture

The application follows a component-based React architecture.

The main parts of the application are organized around:

- Pages and administrative views
- Reusable UI components
- API communication
- Application state management
- Routing
- Forms and validation
- Data visualization

The frontend communicates with backend services through HTTP APIs using Axios.
